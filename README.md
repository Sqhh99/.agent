# .agent

Sqhh99 的 C++ agent skills（V2）。接到任务先读 `skills/cpp-engineering`。

## 总控

- `cpp-engineering` — 工作流、范围、真实性契约

## 工程底座

- `cpp-project-layout` — apps / libs，而不是无限 `core`
- `cpp-build-system` — target-based CMake + presets
- `cpp-dependency-management` — 决策树，不是「慢就 Fetch」
- `cpp-modern-cpp` — RAII、所有权、生命周期
- `cpp-design-and-comments` — 契约与「为什么」，允许 `.cpp` 必要注释
- `cpp-testing-contract` — 场景覆盖；修 bug 先写失败回归
- `cpp-debug-and-quality` — format / tidy / sanitizer
- `cpp-git-workflow` — 分支 PR；长期决策写 ADR
- `cpp-ci-release` — PR 门禁与 tag 发布

## 领域
