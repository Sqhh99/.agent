# 证据、参数与边界表达

## 结论类型

- 已确认事实：由用户材料、现场数据或权威原始来源直接支持；
- 来源支持的结论：由论文、标准、机构报告或官方资料支撑；
- 工程建议值：用于方案设计或招标条件，需要后续标定；
- 工程推断：根据公开信息和工程机理作出的推导，必须显式标注；
- 待现场验证：受海况、底质、噪声、结构、通信或作业条件影响，不能直接承诺。

## 参数表达

不要写“系统可实现 95% 识别率”而没有测试条件。应写明指标定义、样本范围、环境条件、统计方法和验收方式。对声学作用距离、检测概率、误报率、覆盖范围等强环境相关指标，必须注明需通过现场传播试验、标定航行或盲测确定。

## 缺口闭环

P0 缺口未关闭，不得交付；P1 尽力回补，找不到时说明；P2 可作为扩展。连续两轮没有新增高价值证据，且所有 P0 已关闭后方可停止研究。
