# 文档结构模板选择

## 项目建议书

重点回答“为什么建、建什么、怎么建、投入产出如何、如何验收”。

推荐主线：背景与必要性 → 需求与痛点 → 建设目标 → 总体架构 → 分场景方案 → 装备与平台 → 算法与数据 → 实施路线 → 测试验收 → 投资效益 → 风险保障。

## 工程技术解决方案

重点回答“当前问题是什么、传统方式为什么不足、方案如何解决、需要哪些设备、如何落地”。

推荐主线：需求 → 传统方法 → 总体方案 → 系统组成 → 任务流程 → 算法与公式 → 数据平台 → 部署运维 → 验证 → 风险边界。

## 研究型设计报告

重点回答“研究依据是什么、核心难点是什么、技术路线与参数如何推导、如何通过试验验证”。

推荐主线：需求理解 → 研究现状 → 难点 → 指标分解 → 系统设计 → 数学模型/算法 → 仿真试验 → 评价指标 → 工程化与风险。

## 文档结构检查

任何模板都应检查：

1. 每个痛点是否在后文有对应措施；
2. 每个措施是否有设备或算法承载；
3. 每个关键指标是否有验证方法；
4. 每幅图是否解释一个正文中的复杂关系；
5. 结论是否回到最初的需求和指标。
