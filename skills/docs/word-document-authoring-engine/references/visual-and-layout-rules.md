# 图形、表格与 Word 版式规则

## 图形

图形优先级：总体架构图、任务流程图、部署图、算法流程图、数据流图、闭环控制图、实施路线图。每幅图只表达一个主要问题，节点文字短而准确。

图内允许模块名、箭头说明和必要参数，但不放“图 N XXX”的主标题。图题在图片下方。保持边距，避免线条穿过文字，避免低分辨率截图。

## 表格

表格适用于对照，不适用于长篇解释。推荐场景：设备配置、关键指标、阶段成果、风险与对策、验收条件。段落超过三行且无明显对照关系时，应改为正文。

## Word 页面

封面克制，不使用复杂背景。目录清晰。正文标题不与页末孤立。图与图题尽量同页。表头跨页时重复。页眉页脚保持统一。

## 视觉 QA

渲染后逐页检查：文字截断、图片模糊、框线重叠、孤行、表格断裂、标题分页、公式缺字、异常空白和页码错误。任何一项不通过都必须回修。
