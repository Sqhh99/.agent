# 示例调用

## 无人船水文调查

使用本 Skill 编写“无人船 USV 四季水文调查和环境动态监测解决方案”。从应用场景和研究论文出发，先写当前需求与问题、传统人工和船载调查方法，再提出无人船方案，说明设备、算法、数据平台、四季作业策略、实施路线和验收指标。减少表格，配置总体架构图、作业流程图和季节适应策略图，图题在图下，输出 DOCX。

## 海上风电结构健康监测

使用本 Skill 编写项目建议书。重点分析人工潜水巡检在强流、冬季、低能见度环境下的问题，提出 USV+ROV/UUV+声呐/视觉/电化学传感器方案，加入腐蚀评估、冲刷检测、数据融合算法、公式、试验和风险控制，输出正式 Word 文档。

## 既有文档增补

读取既有 Word 方案，将新增的海缆喇叭口牵引线检测、数据分级分类和安全保密机制融入原目录。重新调整章节、交叉引用和图表，不在文末简单追加。完成后逐页渲染检查并输出修订 DOCX。
