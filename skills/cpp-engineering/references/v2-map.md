# C++ skill 地图（V2.1）

接到任务先读 `cpp-engineering`。

| Skill | 管什么 |
| --- | --- |
| cpp-engineering | 工作流、先搜再写、计划步骤字段、真实性、评审挡板入口 |
| cpp-project-layout | 目录与模块边界 |
| cpp-build-system | CMake / presets / 警告 |
| cpp-dependency-management | 依赖决策树 |
| cpp-modern-cpp | RAII / 所有权 / 安全黑名单；深读 `references/core-guidelines-digest.md` |
| cpp-design-and-comments | 契约注释与设计导向 |
| cpp-testing-contract | 测试路径；GTest/CTest 骨架在 templates/ |
| cpp-debug-and-quality | format / tidy / sanitizer / CRITICAL-HIGH 挡板 |
| cpp-git-workflow | GitHub Flow、rebase 红线、三点 diff、ADR |
| cpp-ci-release | PR CI 与 tag 发布 |
| cpp-qt-application | Qt 线程与 UI 边界 |
| cpp-device-io | 协议、DMA、设备 I/O |
